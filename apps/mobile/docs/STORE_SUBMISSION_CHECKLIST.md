# Store Submission Checklist (iOS + Android)

## App metadata

- [ ] App name, subtitle, and descriptions finalized
- [ ] Keywords (iOS) / short description (Android) finalized
- [ ] Categories and content ratings selected
- [ ] Privacy policy and support URLs are live

## Visual assets

- [ ] App icon and splash assets finalized
- [ ] Required screenshots captured for all device sizes
- [ ] Optional preview video prepared (if used)

## Compliance

- [ ] App Store privacy questionnaire completed
- [ ] Google Play data safety completed
- [ ] Export compliance reviewed
- [ ] Third-party integrations disclosed where required

## Build/release readiness

- [ ] Bundle/package identifiers match store records
- [ ] Version + build numbers incremented correctly
- [ ] Production builds succeed
- [ ] Auth smoke checks pass (login, sign-up, session persistence, logout)
- [ ] Release notes drafted
- [ ] `apps/mobile/docs/RELEASE_CHECKLIST.md` completed

## Operations

- [ ] Launch-window monitoring owner assigned
- [ ] Rollout strategy decided (phased/full)
- [ ] User support channel ready
