# Store Submission Checklist (iOS + Android)

## App metadata

- [ ] App name/description finalized and aligned with in-app wording.
- [ ] Keywords (iOS) and short description (Android) finalized.
- [ ] Category and content rating reviewed.
- [ ] Privacy policy + support URLs are live and correct.

## Visual assets

- [ ] App icon/adaptive icon match current assets in `apps/mobile/assets`.
- [ ] Splash assets are final.
- [ ] Screenshots captured for required device sizes.
- [ ] Optional preview video prepared (if used).

## Compliance & privacy

- [ ] App Store privacy questionnaire completed.
- [ ] Google Play data safety form completed.
- [ ] Export compliance reviewed.
- [ ] Third-party auth/analytics disclosures match actual integrations (Supabase Auth + analytics event ingestion).

## Build & config

- [ ] iOS bundle ID is `com.wellnessapp.mobile`.
- [ ] Android package is `com.wellnessapp.mobile`.
- [ ] Version + build numbers incremented.
- [ ] EAS production builds pass.
- [ ] Release notes drafted.

## QA & operations

- [ ] `apps/mobile/docs/RELEASE_CHECKLIST.md` completed.
- [ ] Launch-window monitoring/incident owner assigned.
- [ ] Rollout strategy decided (phased/full).
- [ ] Support channel readiness confirmed.
